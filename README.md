## 📋 Présentation

**SpotRasso** est une plateforme web destinée aux **passionnés d'automobiles et de motos**.

L'objectif est de permettre aux membres de la communauté de découvrir, partager et retrouver facilement des **rassemblements, événements et spots automobiles**.

Le projet a été pensé comme une plateforme communautaire permettant de réunir les passionnés autour d'une même passion : **l'automobile et la moto**.

---

## 🚘 Fonctionnalités

### 📍 Carte des rassemblements

SpotRasso permet de visualiser les différents rassemblements et spots directement sur une carte.

Les utilisateurs peuvent ainsi retrouver facilement les événements présents dans différentes villes.

### 🏁 Rassemblements

Les rassemblements peuvent contenir différentes informations :

- 📍 Ville
- 🗺️ Adresse
- 🚗 Type de rassemblement
- 👥 Nombre de participants
- 💰 Prix
- 📅 Date
- 🕐 Horaires
- 📝 Description
- 🖼️ Image du rassemblement

### 🔎 Recherche

La plateforme permet de retrouver plus facilement les rassemblements selon les informations disponibles.

### 🏍️ Automobile & Moto

SpotRasso est pensé aussi bien pour les passionnés de :

- 🚗 Voitures
- 🏎️ Sportives
- 🛠️ Préparations
- 🏁 Motorsport
- 🏍️ Motos
- 🔧 Mécanique
- 📸 Automobile en général
